# glossary/

Two kinds of terms, kept separate:

- `canonical/` — official Factorio or established community terms.
  **Check https://wiki.factorio.com/Glossary first** when adding or
  verifying one — it's the closest thing Wube has to an authoritative
  term list. It's not exhaustive though: it has no entry for `chunk`
  or `city block`, which needed other sources (`Map_structure`, forum
  usage). Not every canonical term has the same source authority —
  some cite an official wiki tutorial page, some are community-coined
  and only documented in forum usage; each entry states which.
- `invented/` — terms coined inside this project, not used anywhere
  else. One file per term, plain English definition, a note on
  where/why it was coined — see rule 4 in CLAUDE.md.

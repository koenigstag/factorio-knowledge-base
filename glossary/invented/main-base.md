# main base

The heart of a [megabase](../canonical/megabase.md) — the site with the
main bus, the mall, and the science row (`layouts/scalable_main_base.md`),
contrasted with the single-purpose remote
[outposts](../canonical/outpost.md) hanging off it (chem base, solar
base, nuclear base, the remote labs site). Everything a player directly
interacts with day to day — construction materials, personal equipment,
the bulk of the base's own expansion — flows from here, even once most
of the actual production has moved to remote sites.

Not an official Wube term (the wiki's own glossary defines "outpost"
but not a matching name for the non-outpost site an outpost is relative
to) — coined here to name the other half of that relationship
explicitly, since this project's layouts kept needing to say "the main
base" without a defined term for it.

Coined in `layouts/scalable_main_base.md`/`glossary/canonical/megabase.md`
while separating this project's base-type vocabulary; not yet backed by
a `decisions/` ADR.

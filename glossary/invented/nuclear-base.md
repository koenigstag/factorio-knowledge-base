# nuclear base

An [outpost](../canonical/outpost.md) dedicated to uranium mining,
processing, and nuclear power generation — `layouts/nuclear_base.md`.
Exists as its own site because uranium mining needs a steady
`sulfuric-acid` supply (an input this project's
[chem base](chem-base.md) is the natural source of, not the
[main base](main-base.md)) and because a reactor's own footprint,
cooling/heat-pipe layout, and enrichment cycle are large enough to
warrant separation the same way oil processing warranted a chem base.

Coined while separating this project's base-type vocabulary; not yet
backed by a `decisions/` ADR.

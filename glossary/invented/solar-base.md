# solar base

An [outpost](../canonical/outpost.md) dedicated to power generation via
large solar-panel/accumulator fields — `layouts/solar_base.md`. Exists
as its own site (rather than power generation woven into the main base)
because solar/accumulator counts scale with the base's total power
draw, not with any single production block, and a large panel field's
footprint is disproportionate to the power infrastructure a single
main-base block would otherwise host — see
`relations/solar_accumulator_ratio.md` for the per-MW panel/accumulator
counts this site is sized from.

Coined while separating this project's base-type vocabulary; not yet
backed by a `decisions/` ADR.

# module

A category of interchangeable implementations of one [[contract]]
across tiers. Not a file, but a logical group, e.g.
`modules/iron-smelting/{am1-yellow, am2-red}`. Only meant to be
created once a second interchangeable tier of the same functional slot
actually exists — see the `contracts/`/`modules/` rule in CLAUDE.md.

Coined during initial architecture discussion.

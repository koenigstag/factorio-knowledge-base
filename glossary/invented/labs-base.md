# labs base

An [outpost](../canonical/outpost.md) hosting only the lab field,
connected to the [main base](main-base.md) by a dedicated pack train
rather than sitting on-site — designed in
`layouts/scalable_main_base.md`'s "Labs: remote site via dedicated pack
train" section. Deliberately the smallest of this project's outpost
types (no local resource extraction — packs arrive fully finished),
kept remote specifically so a growing lab field never approaches the
main base's own city-block grid footprint, a risk an on-site-but-detached
labs block can't fully rule out.

Coined while separating this project's base-type vocabulary; not yet
backed by a `decisions/` ADR.

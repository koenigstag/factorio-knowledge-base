# tap-module (tap-in / tap-out module)

A functional unit in the gap zone: a splitter/underground belt that
either diverts a share of a resource from the main bus into a city
block (tap-in) or adds a block's output back onto the bus (tap-out).
Envisioned with a fixed position in the first chunk of the gap from
the bus, using the same pattern for input and output (only the
direction differs) — not yet implemented as an actual pattern or
blueprint.

Coined during initial architecture discussion, alongside the
`city-block gap` concept. Not an instance of
[factory module](factory-module.md) despite the shared word — a
tap-module is bus-tapping infrastructure sitting in the gap, not a
production cell inside a block.

# rocket base

An [outpost](../canonical/outpost.md) dedicated to rocket-silo
construction and launches — `low-density-structure`, `rocket-fuel`,
`rocket-part`, and satellite/space-science-pack production. Named here
for consistency with this project's other base-type terms
([chem base](chem-base.md), [solar base](solar-base.md),
[nuclear base](nuclear-base.md), [labs base](labs-base.md)), but **no
layout for it exists yet** — this project already holds some of the
groundwork (`relations/rocket_part_ratio.md`'s ingredient ratios) but
hasn't designed the site itself. Per this project's stated policy of
not scaffolding layouts ahead of content, `layouts/rocket_base.md`
isn't created until there's an actual pattern to write up.

Coined while separating this project's base-type vocabulary; not yet
backed by a `decisions/` ADR.

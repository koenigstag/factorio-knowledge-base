# outpost

Official Wube glossary term for a small, single-purpose remote site
connected to a main base — the general concept this project's own
remote-site patterns are all specific instances of:
`layouts/scalable_chem_base.md`, the remote labs site in
`layouts/scalable_main_base.md`, and each off-grid drill field, all
have exactly this shape (single purpose, physically separate, rail-
connected).

Official Wube glossary:
> "A small base created far away from a main base, usually to serve a
> single purpose like mining or production of a specific resource."
> (wiki.factorio.com/Glossary)

Distinct from [micro-factory](micro-factory.md) (self-contained,
doesn't imply distance or a rail connection specifically) and from
[train-base](train-base.md) (a whole-base organizing pattern where
*every* module is train-connected, not just the remote/single-purpose
ones). An outpost is usually train-connected in practice, but the
official definition itself doesn't require it — the defining trait is
distance + single purpose, not the transport method.

Source: https://wiki.factorio.com/Glossary (official Wube glossary)

# Canonical terms

Official Factorio or established community terms belong here, each
with a source reference. Not every term has the same source authority
— `main-bus.md` cites an official Wube wiki tutorial, `city-block.md`
cites active community forum usage since no official page exists for
it; each entry states which. Cross-links to `glossary/invented/` where
our usage extends or narrows the community meaning.

# train-base (train-heavy / modular train base)

A base-organization approach: production modules are connected to
each other by trains delivering materials point-to-point, instead of
(or in addition to) belts running between them. Contrasts with
[main-bus](main-bus.md), where shared items travel continuously down
belts — here a train run is a discrete, scheduled delivery instead.
Commonly paired with [micro-factory](micro-factory.md)/island-style
modules, since those aren't placed adjacent to each other the way
belt-fed `city-block`s are.

Direct forum quote, describing a base where production modules
("squares") have no belt connections between them at all:
> "The squares are only connected via 1-8 trains."

Community-coined, not an official Wube term. See
[train-configuration-notation.md](train-configuration-notation.md)
for the shorthand (`2-4-2`, etc.) used to describe individual trains'
locomotive/wagon makeup within a train-base.

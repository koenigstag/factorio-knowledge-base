# examples/

`relations/` gives you the answer. `examples/` gives you the method —
a walkthrough of going from a question to an answer using
`formulas/` + `datapacks/`/`mechanics/`, so the same pattern can be
applied to a question that isn't already cached in `relations/`.

Each file: the question in plain English, which files to read, the
actual formula call, and the result — cross-checked against the
matching `relations/` entry where one already exists.
